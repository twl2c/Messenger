# Messenger
## Описание:
### Предметная область:
Данный проект представляет собой базу данных для мессенджера. Система позволяет пользователям общаться друг с другом в личных и групповых чатах, отправлять сообщения, прикреплять файлы и ставить реакции на сообщения.
### Проблема, которую реашет:
База данных решает задачу хранения информации о пользователях, чатах, участниках чатов и отправленных сообщениях. Также предусмотрено хранение вложений и реакций пользователей на сообщения.
