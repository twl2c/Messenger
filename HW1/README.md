# HW1 — Запросы на реляционной алгебре

## Запрос 1
### Формулировка на естественном языке:
Найти имена и email пользователей, которые находятся онлайн.
### Запись на реляционной алгебре:
π(username, email)(σ(status = 'online')(users))
## Запрос 2
### Формулировка на естественном языке:
Найти пользователей и сообщения, которые они отправили.
### Запись на реляционной алгебре:
users ⋈ users.user_id = messages.user_id messages
